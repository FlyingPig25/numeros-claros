# Números Claros

Landing page del producto digital **Números Claros**: un kit de planillas para Google Sheets y Excel, pensado para quien vende en Argentina.

El sitio es estático y se sirve con GitHub Pages desde la raíz del repositorio (`index.html`). El archivo `.nojekyll` evita que Jekyll procese la página.

## Placeholders pendientes

En `index.html` quedan estos textos para completar más adelante:

- `{{PAYHIP_CHECKOUT_URL}}`
- `{{URL_BOTON_ARREPENTIMIENTO}}`
- `{{EMAIL_CONTACTO}}`
- `{{NOMBRE_Y_CUIT_DEL_TITULAR}}`

La página lleva `<meta name="robots" content="noindex, nofollow">` hasta que esté lista para los buscadores.
